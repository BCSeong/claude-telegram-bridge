# claude-telegram-bridge

Talk to your PC's Claude Code session from your phone over Telegram.

## Setup

```powershell
# 1. Create your own Telegram bot via @BotFather
# 2. Clone this repo and run:
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -WorkDir "C:\your\project"
# 3. Double-click claude-telegram.bat on your desktop
```

Each person needs their own bot — one bot token supports only one polling session at a time.
